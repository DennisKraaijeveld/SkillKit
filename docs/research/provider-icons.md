# AI agent host and provider icon research

Verified against first-party product sites, documentation, and official GitHub repositories on 2026-08-27.

## Recommendation

Skillbook should call these products **agent hosts** or **coding-agent tools**, not model providers. OpenCode, Crush, goose, and Kimchi can each use several model providers; “provider” in the UI should mean the tool that owns the skills directory.

The defensible current catalog is:

- Keep every harness already detected by Skillbook: Claude Code, Cursor, Codex, OpenCode, Gemini CLI, Windsurf, GitHub Copilot, OpenClaw, Crush, Devin, goose, and Kimchi.
- Add **Google Antigravity CLI** when its `~/.gemini/antigravity-cli/skills` directory is supported. Google moved individual Gemini CLI users to Antigravity CLI on 2026-06-18; Gemini CLI remains relevant for enterprise/API-key users and backward compatibility. ([Google announcement](https://github.com/google-gemini/gemini-cli/discussions/28017), [Antigravity product announcement](https://www.antigravity.google/blog/introducing-google-antigravity-cli))
- Do not make plain `GitHub` a second product beside GitHub Copilot. `.github/skills` is a placement convention; the user-facing agent product is **GitHub Copilot**. A generic GitHub mark is still reasonable for source/origin UI.
- Do not expand the first pass to every name accepted by ecosystem scanners. This set covers Skillbook's actual harnesses plus Google's current successor. Add another tool only when Skillbook also has a verified detection path and first-party identity/source.

Important current naming:

- **Devin is made by Cognition.** Cognition's official GitHub organization describes itself as “Makers of Devin”; use `CognitionAI`, not similarly named unofficial accounts. ([Cognition GitHub](https://github.com/CognitionAI), [Devin](https://devin.ai/))
- **Windsurf is now owned by Cognition.** Windsurf's first-party site footer names Cognition AI, while older official editor-plugin repositories remain under the verified `Exafunction` organization. There is no public repository for the Windsurf editor itself. ([Windsurf](https://windsurf.com/), [Exafunction GitHub](https://github.com/Exafunction))
- **goose is no longer canonically `block/goose`.** The project moved to the Agentic AI Foundation at the Linux Foundation; the canonical repository is `aaif-goose/goose`. ([repository](https://github.com/aaif-goose/goose), [governance](https://github.com/aaif-goose/goose/blob/main/GOVERNANCE.md))
- **OpenCode's current repository is `anomalyco/opencode`.** The old `opencode-ai/opencode` repository is archived. ([current repository](https://github.com/anomalyco/opencode), [Anomaly GitHub](https://github.com/anomalyco))

## Asset handling contract

For shareable, reviewable assets inside this repository:

1. Prefer an official brand kit or an icon committed in the canonical repository. Use a product-site favicon only when no maintained kit/repo mark exists.
2. Do not hotlink runtime UI assets. Vendor a stable copy under the app asset catalog so builds are reproducible and work offline.
3. Preserve the original download alongside the normalized Xcode asset when practical. Do not trace, redraw, recolor, crop, or “clean up” vendor marks.
4. Record product, owner, canonical product/repo URL, exact asset URL, retrieval date, upstream commit/tag when applicable, SHA-256, original license, brand-policy URL, and transformation in the provenance manifest.
5. A repository's MIT/Apache/FSL license is not automatically a trademark license. The UI use is nominative: a small mark next to the exact product name, subordinate to Skillbook's own brand, with no endorsement language.
6. Keep color marks in original rendering mode. Only use template rendering for an official monochrome asset supplied for that purpose; converting a color logo into a template can violate brand guidance and destroy recognition.
7. Favicons are often tiny multi-resolution ICOs. Prefer the official SVG or 192 px+ PNG when available, then use the original ICO only as a fallback source.

## Exclusions and traps

- Do not use unofficial lookalike Devin repositories. The authoritative namespace is [`CognitionAI`](https://github.com/CognitionAI).
- Do not source OpenCode from archived [`opencode-ai/opencode`](https://github.com/opencode-ai/opencode); use Anomaly's current repository.
- Do not source goose from `block/goose`; the current canonical repository is `aaif-goose/goose`.
- Do not reuse the deprecated GitHub Copilot robot-head artwork found in older icon libraries. Skillbook uses the current Octicons `copilot-48` product glyph beside the explicit Copilot name.
- Do not infer permission from an icon appearing in a favicon, npm package, or open-source repository. Record provenance and the applicable brand terms separately.
